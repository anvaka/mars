# Fonts

Glyphs of [Noto Sans](https://fonts.google.com/noto/specimen/Noto+Sans) that the map uses for its labels. The font
is licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/).

The files come from https://github.com/protomaps/basemaps-assets. Each file holds 256 characters, and only the
ranges that the names on Mars need are here. `tools/build_labels.py` prints which ranges those are.
